Working prototype of the Supervisor redesign (Instrument direction). Everything is mock data; interactions that matter are real — modals stack and trap focus, the machine switcher switches, Ctrl arms, logs stream, selection and clipboard bars work. Resize to 390px for the mobile layout. g+s/f/c/p/y/t jumps tabs, ? opens Request-a-change.

Try these
  • Tap the machine chip (top left) — switch to verdant, note the background texture, chip, and confirm dialogs all change
  • In the switcher: atlas shows the unreachable state, mira the not-signed-in state
  • Sessions → any card → live log with find, prev/next, follow-pause
  • Console → tap Ctrl — it arms and pulses until the next key
  • Files → long-press (or Ctrl+click) a file for multi-select; Copy → clipboard bar appears
  • System → Shut down — password re-prompt with machine identity repeated
